##  About the Portfolio Codebase

- Built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**
- Multi-page layout: Home, Featured Projects, and Contact
- Dynamic Open Graph image so links look great when shared on LinkedIn and X
- Statically exported and deployed to **GitHub Pages**

### Project structure

```
app/          Pages, layouts, and routes
components/   Reusable UI components
lib/          Helpers and content data
public/       Static assets (images, resume)
docs/         Exported site served by GitHub Pages
```

##  Run It Locally

```bash
git clone https://github.com/TrustEmmanuel/portfolio.git
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
